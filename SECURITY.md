# Security policy

## Reporting a vulnerability

Use the private GitHub Security Advisory form at [Report a vulnerability](https://github.com/draarivpatel-ui/studio/security/advisories/new). Do not open a public issue, pull request or discussion with exploit details.

Never include a live secret, token, cookie, private key or personal data in a report. Use synthetic values and redacted transcripts.

## Supported versions

| Version | Status |
| --- | --- |
| latest default branch | Supported |

Security fixes are applied to the latest state of the default branch.

## Scope

This policy covers the static site generator, generated charity case-study pages, local assets and the static accessibility audit tooling. In scope are script or HTML injection through site data, broken local asset validation, unsafe generated markup and audit bypasses. Browser, operating system and physical-device vulnerabilities are out of scope.

## Coordinated disclosure

- Acknowledgment within 3 business days.
- Initial triage within 14 calendar days.
- Fix or mitigation target within 90 calendar days for confirmed reports.
- Public disclosure timing is coordinated with the reporter, normally within 90 days.
